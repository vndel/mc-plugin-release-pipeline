# Release checklist

- [ ] Confirm supported Minecraft and Java versions in plugin metadata.
- [ ] Run unit tests and a clean package build.
- [ ] Test on a disposable Paper server matching the declared minimum.
- [ ] Review dependency licenses and shaded-package relocation.
- [ ] Check that configuration defaults migrate safely.
- [ ] Publish jar plus SHA-256 checksum and concise changelog.
- [ ] Verify the release asset can be downloaded without authentication.
